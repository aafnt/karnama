# کلید امضای «کارنما»

فایل `karnama-release.jks` در همین پوشه، کلید امضای دائمی اپلیکیشن است.

**این فایل را حذف، جابه‌جا یا با یک Keystore جدید جایگزین نکنید.**

اگر این فایل عوض شود، امضای دیجیتال APKهای بعدی با نسخه‌های قبلی فرق
می‌کند و اندروید دیگر آن‌ها را «همان برنامه» نمی‌شناسد؛ در نتیجه کاربران
برای نصب نسخه‌ی جدید باید ابتدا نسخه‌ی قبلی را با از دست دادن تمام
داده‌هایشان Uninstall کنند.

مشخصات (فقط برای اطلاع، نیازی به تغییر نیست):

- Alias: `karnama`
- الگوریتم: RSA 2048-bit
- اعتبار: ۳۰ سال

رمزهای پیش‌فرض در `app/build.gradle.kts` تعریف شده‌اند و برای ساخت
خودکار در GitHub Actions به همین شکل کافی‌اند. در صورت نیاز به امنیت
بیشتر، می‌توانید رمزها را (نه خود فایل Keystore را) از طریق GitHub
Secrets و متغیرهای محیطی `KARNAMA_KEYSTORE_PASSWORD` و
`KARNAMA_KEY_PASSWORD` بازنویسی کنید.
